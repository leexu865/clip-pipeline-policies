Clip Pipeline

A local, single-operator tool for generating and publishing short-form video content.

What it does

Clip Pipeline runs on its operator's own computer. It generates short story-narration videos and publishes them to social accounts the operator owns, using each platform's official API. It has one user — the person running it — and is not distributed or offered as a service to anyone else.
